## 열기

preview/index.html을 Chrome 또는 Edge에서 여세요. 각 페이지는 pages/에 있으며 공통 CSS/JS를 상대 경로로 사용합니다. 서버·설치·WordPress·인터넷 없이 확인할 수 있습니다. 모바일 기기 실물에서는 이 폴더 전체를 복사해 열거나 별도로 승인한 로컬 정적 서버를 사용하세요. PC의 file 주소는 휴대폰에서 접근할 수 없습니다.

브라우저 개발자 도구의 기기 모드에서 390px 등을 선택하고 200% 확대·키보드 Tab/Escape로 확인하세요. 모바일 폭 시뮬레이션은 실제 휴대폰 검증이 아닙니다.

## 파일

- index.html: 20화면·유형별 필터·AP01~AP11 검토 표시. 승인 저장 기능 아님.
- pages/01-page.html ~ 20-page.html: 실제 페이지별 시안.
- assets/css/preview.css, assets/js/preview.js: 공통 디자인·모의 기능.
- assets/images/*-placeholder.svg: 새로 작성한 임시 자리. 실제 제품이나 회사 사례가 아님.
- page-map.json: 원본 URL과 로컬 파일 대응.
- VALIDATION.md: 검증 범위·차이·미확인 사항.

## 데이터와 안전 범위

원문은 docs/audit/의 2026-10-26 HTML 조사 기록에서 가져왔습니다. 하단 원문/이미지 참조 기록으로 추적할 수 있습니다. 실제 이미지의 사용 허가·내용·모델 대응은 미확인이라 자동 로딩하지 않습니다. 외부 원문 링크는 사용자가 클릭할 때만 이동합니다.

실제 form/action·네트워크 전송·메일 링크·DB·결제·추적 스크립트·저장소 API는 연결하지 않았습니다. 문의는 테스트 정보만 입력하세요. 선택 파일의 내용도 읽지 않습니다. 브라우저 자체의 동작까지 제어하는 개인정보 처리 정책은 아니며 실제 개인정보는 넣지 마세요.

기존 docs/design/themes는 변경하지 않습니다. WordPress 구현·배포·Git 커밋/Push는 별도 범위입니다.
