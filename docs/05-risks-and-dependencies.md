# 위험 및 의존성

작성일: 2026-10-26. 위험은 발생 가능성과 영향을 정리한 것으로, 실제 장애·침해·파일 노출을 확인했다는 의미가 아니다. 이번 작업에서는 운영 서버·DB 접근, 취약점 탐색, 백업 URL 추측 요청을 수행하지 않았다.

## 운영 서버 보안과 민감정보

문서·스크린샷·커밋에는 FTP/SFTP 비밀번호, wp-config 원문, DB 자격증명, 인증키, 고객 문의·주문 데이터를 넣지 않는다. 보안 검토가 필요해도 민감정보를 외부 분석 서비스에 업로드하지 않는다.

공개 HTML의 버전 문자열만으로 실제 설치 버전이나 취약점을 확정하지 않는다. 업데이트는 테마 리디자인과 별도로 호환성·백업·승인이 필요한 변경이다. 서버에 코드를 실행하거나 파일을 올려 검사하지 않는다.

## 백업·설치 파일 노출 가능성

로컬 Twenty Seventeen에 `.orig` 파일이 존재한다는 사실은 확인됐다. 이것이 운영 웹에서 접근 가능하거나 비밀을 포함한다는 증거는 없다. 로컬 `.vscode/sftp.json` 역시 설정 파일 존재만 확인했으며 웹 공개 여부는 알 수 없다.

운영 담당자가 웹 루트 내 SQL 덤프·압축 백업·설치 스크립트·편집기 백업·설정 복사본의 유무와 접근 제어를 확인하도록 한다. 점검은 파일명과 위치 등 최소한의 메타데이터로 시작한다. 별도 승인 없이 후보 URL을 대입하거나 발견 파일을 다운로드·이동·삭제하지 않는다. 실제 노출이 확인되면 접근 제한·자격증명 교체 필요성을 담당자와 판단한다.

## 레거시 URL 및 SEO

기존 경로에는 한글 슬러그, `room/` 상세 경로, www / 비www 혼용이 있다. 경로가 낡아 보인다는 이유로 변경하지 않는다. 메뉴에서 발견되지 않은 게시물·첨부·과거 캠페인 경로가 더 있을 수 있다. 20개 경로를 전체 색인 목록으로 간주하지 않는다.

URL 변경 필요 시 기존→신규의 일대일 매핑, 리다이렉트 체인·루프, 대표 도메인, canonical, 내부 링크, 사이트맵을 함께 검수한다. 검색 도구·로그 접근은 아직 확보되지 않았으며 성과 지표도 미확인이다.

## 진행 조건과 담당 결정

- 테마 구조 확정: 활성 구성과 실제 기능 의존성 확인 후.
- 개발 실행: 로컬 DB·외부 발송 차단과 비공개 자료 보관 방식 확정 후.
- 콘텐츠 재작성·이미지 교체: 운영 담당자의 사실·권리 검토 후.
- 배포: 사용자 명시적 승인, 합의된 수단, 검수 및 롤백 준비 후. FTP/SFTP 운영 변경 금지 유지.
