# 공통 내비게이션·헤더·푸터 평가

작성일: 2026-10-26 (KST)

이 문서는 PHASE A의 HTML 소스 기록을 근거로 한 PHASE B 평가다. 운영 사이트 재접속·화면 렌더링·이미지 판독·폼 제출은 수행하지 않았다. **사실**은 수집 시점의 audit 기록, **위험 가설**은 예상 영향이며 실사용 장애를 확인했다는 뜻이 아니다. 검토 의견은 PHASE C 확정안이나 구현 지시가 아니다.

중요도: P0는 주문·문의 핵심 과업 또는 정보 보존을 위해 우선 검증할 사항, P1은 탐색·이해·접근성의 주요 검토 사항, P2는 보조 일관성·운영 정리 사항이다. 중요도와 확인 수준은 별개다. P0 가설도 검증 전 장애로 확정하지 않는다.

## 평가 대상과 실제 구조

대상 URL은 [색인의 20개 경로](00-evaluation-index.md#평가-범위) 전체다. 근거는 각 audit의 「공통 헤더 — 소스 등장 순서」「공통 푸터 — 소스 등장 순서」「조사 정보」 및 [audit 색인](../audit/00-audit-index.md) 「공통 영역 문자열 비교」다.

헤더 순서는 연락처·주소 → 로고 링크/이미지 → 메뉴 토글 → 회사소개/기술/증빙 → 추모용 전체/6개 상세 → 기록물 전체/3개 상세 → 신제품/R&D·테마파크 → 오시는길이다. 상위·하위 구조는 PHASE A 기록의 순서를 기준으로 하며 실제 펼침 동작은 미검증이다. 주문·문의는 제품 목록·상세에서 연결되며 추출된 공통 헤더 메뉴에는 독립 주문·문의 항목이 없다.

푸터는 20개 모두 동일 문자열 해시이며 저작권 2020 문구와 대표/개인정보관리책임자 텍스트가 기록돼 있다. 헤더 해시 차이는 활성 메뉴 클래스·공백 차이일 수도 있어 디자인 불일치로 취급하지 않는다.

## 반복과 누락의 해석

연락처·제품 문의 준비 항목 반복은 문맥을 유지하는 장점도 있다. 반복 횟수만으로 제거하지 않는다. audit 추출은 ARIA·모든 CSS·동적 요소를 보존하지 않으므로 접근 가능한 메뉴 이름, 현재 위치 표시, 실제 드롭다운 구조의 부재를 확정할 수 없다. 모든 경로와 콘텐츠는 유지하며 메뉴 재편은 후속 검토 대상이다.
