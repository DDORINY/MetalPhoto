# 주문·문의 흐름 평가

작성일: 2026-10-26 (KST)

이 문서는 PHASE A의 HTML 소스 기록을 근거로 한 PHASE B 평가다. 운영 사이트 재접속·화면 렌더링·이미지 판독·폼 제출은 수행하지 않았다. **사실**은 수집 시점의 audit 기록, **위험 가설**은 예상 영향이며 실사용 장애를 확인했다는 뜻이 아니다. 검토 의견은 PHASE C 확정안이나 구현 지시가 아니다.

중요도: P0는 주문·문의 핵심 과업 또는 정보 보존을 위해 우선 검증할 사항, P1은 탐색·이해·접근성의 주요 검토 사항, P2는 보조 일관성·운영 정리 사항이다. 중요도와 확인 수준은 별개다. P0 가설도 검증 전 장애로 확정하지 않는다.

## A19 — 주문하기

- **페이지 URL:** http://www.gomemo.net/order_question/
- **근거:** [audit/19-page.md](../audit/19-page.md)의 「조사 정보」「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」. 공통 메뉴는 「공통 헤더」「공통 푸터」 참조.
- **전달 목적(해석):** 이메일 주문에 필요한 정보·사진·일정·조건을 안내하는 목적.
- **실제 확인된 사실:** 이메일로 주문서와 사진을 보내도록 안내하며 필수 항목·원본/우편 전달·제작 기간·상담·공지 순으로 이어진다. 본문에 주문 입력 폼은 추출되지 않았다.
- **정보 구조 문제 또는 위험 가설:** 주문 CTA를 눌렀을 때 온라인 접수 대신 외부 메일 작성이 필요하므로 기대 불일치와 수기 누락 위험.
- **정보·안내 충실성:** 기간·연락 방법·조건은 상세하다. 실제 최신 운영 조건인지 담당자 확인 필요.
- **제목·본문·이미지 관계:** 제목·여러 h2/h3/h4·강조·줄바꿈 텍스트 구조이며 글자 크기는 미확인.
- **탐색·다음 행동:** 목적지 이메일은 명시. 전송 완료·접수 확인은 사이트에서 확인하지 못했다.
- **고연령층 UX 가설:** 테두리라인 명칭·원본 파일·메일 제목·우편 발송 등 여러 규칙을 기억해야 할 가능성. 개인차가 있으므로 연령만으로 어려움을 확정하지 않는다.
- **예상 사용자 영향:** 사진 첨부·양식 복사·규격 전달 중 이탈하거나 주문 정보를 빠뜨릴 수 있다.
- **중요도:** P0 — 핵심 전환 흐름 우선 검증.
- **추가 검증 자료:** 메일 앱 전환·양식 복사 과업, 담당자 최신 정책, 모의 접수 확인. 모든 글꼴 크기·색 대비·이미지 선명도·모바일 배치는 미검증.
- **개선 검토 항목(미확정):** 실제 이메일 절차를 유지한 채 안내 구분·준비 목록·진입 설명의 충분성 검토. 폼 전환을 확정하지 않는다.

## A20 — 문의하기

- **페이지 URL:** http://www.gomemo.net/room/qu/
- **근거:** [audit/20-page.md](../audit/20-page.md)의 「조사 정보」「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」. 공통 메뉴는 「공통 헤더」「공통 푸터」 참조.
- **전달 목적(해석):** 연락 정보·문의·첨부를 접수하는 목적.
- **실제 확인된 사실:** title은 qu, 본문은 문의접수/문의하기. 이름·tel·email·문의사항 type=text·jpg 파일·보내기와 첨부 실패 시 이메일 안내가 있다.
- **정보 구조 문제 또는 위험 가설:** 문서 제목이 목적을 설명하지 못함. 긴 문의 입력·첨부 제한·오류/성공 안내와 라벨 연결은 미검증.
- **정보·안내 충실성:** 필요한 입력 범주는 존재. 필수 여부·허용 크기·보안·수집 안내는 audit 추출만으로 확정 불가.
- **제목·본문·이미지 관계:** 빈 h5 뒤 문의접수와 입력 요소가 이어진다. 이미지 참조는 본문 0개.
- **탐색·다음 행동:** 보내기 버튼과 이메일 대안이 존재하나 전송·수신 성공은 미시험.
- **고연령층 UX 가설:** H.P 약어·파일 확장자·긴 문의의 한 줄 입력이 부담일 가능성. 개인차가 있으므로 연령만으로 어려움을 확정하지 않는다.
- **예상 사용자 영향:** 탭/방문기록에서 페이지를 찾기 어렵거나 긴 문의·첨부 단계에서 부담이 생길 수 있다.
- **중요도:** P0 — 핵심 전환 흐름 우선 검증.
- **추가 검증 자료:** 접근 가능한 이름·필수/오류·첨부 제한·개인정보 안내·격리된 모의 발송. 모든 글꼴 크기·색 대비·이미지 선명도·모바일 배치는 미검증.
- **개선 검토 항목(미확정):** 목적에 맞는 제목·긴 문의 입력·첨부 조건·오류/성공 안내 및 라벨 연결 검토.

## 운영 정책 취급

반품·취소·디자인 비용·제작 기간은 사이트에 기록된 문구이며 현재 정책의 정확성이나 법적 효력을 검증한 것이 아니다. 문구를 사실 확인 없이 완화·강화·삭제하지 않는다. 고객 정보·실제 첨부·세션 값은 평가에 기록하지 않는다.
