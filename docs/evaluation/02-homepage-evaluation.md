# 홈페이지 평가

작성일: 2026-10-26 (KST)

이 문서는 PHASE A의 HTML 소스 기록을 근거로 한 PHASE B 평가다. 운영 사이트 재접속·화면 렌더링·이미지 판독·폼 제출은 수행하지 않았다. **사실**은 수집 시점의 audit 기록, **위험 가설**은 예상 영향이며 실사용 장애를 확인했다는 뜻이 아니다. 검토 의견은 PHASE C 확정안이나 구현 지시가 아니다.

중요도: P0는 주문·문의 핵심 과업 또는 정보 보존을 위해 우선 검증할 사항, P1은 탐색·이해·접근성의 주요 검토 사항, P2는 보조 일관성·운영 정리 사항이다. 중요도와 확인 수준은 별개다. P0 가설도 검증 전 장애로 확정하지 않는다.

## A01 — 홈

- **페이지 URL:** http://gomemo.net/
- **근거:** [audit/01-page.md](../audit/01-page.md)의 「조사 정보」「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」. 공통 메뉴는 「공통 헤더」「공통 푸터」 참조.
- **전달 목적(해석):** 두 제품군을 소개하고 탐색을 시작하게 하는 목적(콘텐츠에서 해석).
- **실제 확인된 사실:** 기록·의병사진 문구 다음에 추모 영정과 기록물/기념물 이미지 링크가 등장한다. 본문 이미지 3개는 alt/title이 비어 있다.
- **정보 구조 문제 또는 위험 가설:** 브랜드 문구와 제품 선택 사이의 관계가 설명 없이 전달될 가능성. 이미지 링크의 목적이 보조기술에서 불명확할 위험.
- **정보·안내 충실성:** 본문의 주장과 제품군 소개는 있으나 제품 선택 기준·주문 절차의 상세 텍스트는 이 구역에서 확인되지 않는다.
- **제목·본문·이미지 관계:** h2 문구→h4 제품군→h6 설명이며 이미지가 링크 안에 있다. 이 구조가 시각적 크기를 증명하지는 않는다.
- **탐색·다음 행동:** 사진 클릭 안내가 존재하지만 실제 클릭 가능한 범위·접근 가능한 이름은 브라우저 확인 필요.
- **고연령층 UX 가설:** 사진 클릭에 익숙하지 않거나 나노hole·스텐 등의 용어를 모르면 진입을 망설일 가능성. 개인차가 있으므로 연령만으로 어려움을 확정하지 않는다.
- **예상 사용자 영향:** 제품군을 고르기 전에 의미를 해석해야 하거나 링크를 놓칠 수 있다.
- **중요도:** P1 — 정보 이해·탐색 우선 검토.
- **추가 검증 자료:** PC/모바일 첫 화면, 이미지 링크 접근 가능한 이름, 제품군 찾기 과업. 모든 글꼴 크기·색 대비·이미지 선명도·모바일 배치는 미검증.
- **개선 검토 항목(미확정):** 핵심 문구·두 제품군 링크의 설명과 연결 관계 검토. 보존 기간·제품 수 주장은 사실 검증 전 확대 재사용하지 않는다.

## 구별해야 할 판단

홈 소스의 제목 계층과 빈 alt는 확인할 수 있지만, 이를 근거로 화면의 글자가 작거나 이미지가 흐리다고 결론 내리지 않는다. 이미지에 있는 문구와 CSS/JS가 제공하는 추가 정보는 아직 미확인이다. 홈에서 주문·문의로 가는 경로는 본문뿐 아니라 공통 메뉴를 포함해 실제 과업으로 확인해야 한다.
