# 회사·기술·신사업·방문 안내 평가

작성일: 2026-10-26 (KST)

이 문서는 PHASE A의 HTML 소스 기록을 근거로 한 PHASE B 평가다. 운영 사이트 재접속·화면 렌더링·이미지 판독·폼 제출은 수행하지 않았다. **사실**은 수집 시점의 audit 기록, **위험 가설**은 예상 영향이며 실사용 장애를 확인했다는 뜻이 아니다. 검토 의견은 PHASE C 확정안이나 구현 지시가 아니다.

중요도: P0는 주문·문의 핵심 과업 또는 정보 보존을 위해 우선 검증할 사항, P1은 탐색·이해·접근성의 주요 검토 사항, P2는 보조 일관성·운영 정리 사항이다. 중요도와 확인 수준은 별개다. P0 가설도 검증 전 장애로 확정하지 않는다.
이 문서는 회사소개(02), 기술(03), 증빙(04), 신제품(16), 테마파크(17), 오시는길(18)을 다룬다. 모든 숫자는 audit 페이지 번호다.

## A02 — 회사소개 / Portfolio

- **전달 목적(해석):** 회사와 실적을 소개해 신뢰를 형성하는 목적(제목에서 해석).
- **실제 확인된 사실:** 개별 본문은 회사소개 (Portfolio) 제목 다음 이미지 참조 45개로 구성되며 별도 설명 텍스트가 추출되지 않았다. 해당 이미지 alt/title은 비어 있다.
- **정보 구조 문제 또는 위험 가설:** 회사·실적 정보가 이미지에 의존할 가능성. 이미지 내부 설명은 아직 읽지 않아 내용 부족을 확정할 수 없다.
- **정보·안내 충실성:** 회사 정보가 이미지에 충분히 있는지 미확인. 이미지 개수를 사례 수로 계산하지 않는다.
- **제목·본문·이미지 관계:** 제목 다음 이미지 연속 구조로, 제목과 각 사례의 의미 연결을 소스 설명만으로 확인하기 어렵다.
- **탐색·다음 행동:** 개별 본문에서 다음 행동 링크는 추출되지 않았다. 공통 메뉴는 별도로 존재한다.
- **고연령층 UX 가설:** 연속 이미지에서 원하는 항목을 찾고 확대하는 과정이 부담일 가능성. 개인차가 있으므로 연령만으로 어려움을 확정하지 않는다.
- **예상 사용자 영향:** 텍스트 검색·읽어주기·원하는 실적 찾기가 어려울 수 있다.
- **중요도:** P1 — 정보 이해·탐색 우선 검토.
- **추가 검증 자료:** 45개 참조의 실물·이미지 내 글씨·중복 여부, 회사 소개/실적 찾기 과업. 모든 글꼴 크기·색 대비·이미지 선명도·모바일 배치는 미검증.
- **개선 검토 항목(미확정):** 각 이미지 내용 확인 후 회사 소개와 실적의 설명·분류·출처 텍스트 필요성 검토.

- **추가 검증 자료:** 실제 주소 담당자 확인, 지도/전화 링크·동적 화면, 방문 과업. 모든 글꼴 크기·색 대비·이미지 선명도·모바일 배치는 미검증.
- **개선 검토 항목(미확정):** 도로명/지번 일치·방문 조건·지도/전화 연결 필요성 검토.

## 공통 비교 의견

회사소개는 이미지 중심, 기술소개는 텍스트 중심, 신제품은 연락처와 단일 이미지 중심이라는 소스 차이가 있다. 이는 정보 제공 방식 차이이며 시각 디자인 불일치나 어느 페이지의 실패를 증명하지 않는다. 기술 수치·수상·인증은 회사 담당자의 증빙과 이미지 실물 확인 후 평가를 보완해야 한다. 원문의 주장이나 정책을 임의로 수정하지 않는다.
