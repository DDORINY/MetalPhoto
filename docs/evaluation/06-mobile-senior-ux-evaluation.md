# 모바일·고연령층 UX 위험 가설

작성일: 2026-10-26 (KST)

이 문서는 PHASE A의 HTML 소스 기록을 근거로 한 PHASE B 평가다. 운영 사이트 재접속·화면 렌더링·이미지 판독·폼 제출은 수행하지 않았다. **사실**은 수집 시점의 audit 기록, **위험 가설**은 예상 영향이며 실사용 장애를 확인했다는 뜻이 아니다. 검토 의견은 PHASE C 확정안이나 구현 지시가 아니다.

중요도: P0는 주문·문의 핵심 과업 또는 정보 보존을 위해 우선 검증할 사항, P1은 탐색·이해·접근성의 주요 검토 사항, P2는 보조 일관성·운영 정리 사항이다. 중요도와 확인 수준은 별개다. P0 가설도 검증 전 장애로 확정하지 않는다.

## 판단 경계

고연령층을 동일한 능력·선호 집단으로 취급하지 않는다. 읽기·기억·정밀 조작·앱 전환에 부담이 있는 사용자도 수행 가능한지 검증한다. 기존 design/ 시안의 18px·버튼 수치는 운영 사이트 측정값이 아니며 본 평가에 사용하지 않았다.

## 아직 평가하지 않은 항목

글꼴 크기·줄 길이·색상 대비·터치 대상 크기·스크롤 거리·가로 넘침·고정 요소 가림·이미지 선명도는 전부 미검증이다. viewport와 계산 스타일을 확보하지 않고 수치·합격/실패 판정을 쓰지 않는다. 제목 태그 수준은 텍스트 크기와 구별한다.

## 초기 검증 과업 제안(미확정)

사용자의 동의를 받아 제품군 찾기 → 특정 모델 구분 → 주문 준비, 적용 사례 찾기 → 문의 초안 작성, 회사 위치 찾기를 관찰한다. 성공/도움 필요/중단, 오류 위치, 사용자 설명을 기록한다. 소수의 관찰을 모든 고연령 사용자에게 일반화하지 않는다. 원본 시안·운영 사이트를 변경하지 않는다.
