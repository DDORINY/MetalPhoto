# 남은 시각·동작 검증

작성일: 2026-10-26 (KST)

이 문서는 PHASE A의 HTML 소스 기록을 근거로 한 PHASE B 평가다. 운영 사이트 재접속·화면 렌더링·이미지 판독·폼 제출은 수행하지 않았다. **사실**은 수집 시점의 audit 기록, **위험 가설**은 예상 영향이며 실사용 장애를 확인했다는 뜻이 아니다. 검토 의견은 PHASE C 확정안이나 구현 지시가 아니다.

중요도: P0는 주문·문의 핵심 과업 또는 정보 보존을 위해 우선 검증할 사항, P1은 탐색·이해·접근성의 주요 검토 사항, P2는 보조 일관성·운영 정리 사항이다. 중요도와 확인 수준은 별개다. P0 가설도 검증 전 장애로 확정하지 않는다.

## 검증 기록 형식

검증 ID / 페이지 URL / 최종 URL / KST 시각 / 장치·브라우저 / 뷰포트 / 확대율 / 수행 과업 / 실제 관찰 / 캡처·로그 위치 / 통과·실패·미확인 / 기존 가설 변경 여부를 기록한다. 요청 전후 변경·발송이 발생하는 시험은 허가와 격리 환경 없이는 수행하지 않는다.

320·360·390·430·768·1024·1440px 및 200/400% 확대는 후보 검증 범위이며 이번에 실행한 결과가 아니다. 개인정보·세션·인증값을 캡처나 네트워크 로그에 남기지 않는다.

## 이번 단계 종료와 후속 조건

PHASE B 문서 작성 완료는 화면 검증 완료·디자인 승인·기능 정상·배포 준비를 의미하지 않는다. 검증 자료를 확보해 P0/P1 가설을 재판정한 후 PHASE C에서 유지·재배치·추가 후보를 검토한다. 현재 새 메뉴·컴포넌트·문구·HTML은 확정하거나 구현하지 않았다.
