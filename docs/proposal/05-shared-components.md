# 공통 컴포넌트 제안

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

상태 구분: **AS-IS**는 PHASE A에서 수집한 소스의 사실, **ISSUE**는 PHASE B의 문제 또는 검증 가설, **TO-BE**는 신규 제안, **APPROVAL REQUIRED**는 내부 컨펌 필요, **UNVERIFIED**는 추가 검증 필요다. 제안 수치·문구·화면 순서는 승인된 확정값이 아니다. 화면 렌더링·이미지 실물·모바일 동작을 검증한 것으로 취급하지 않는다.

## AS-IS

[제품 평가 PR01~04](../evaluation/04-product-information-evaluation.md)는 채널·추천 링크·복합 분야·이미지 확대를, [주문 평가 OI01~05](../evaluation/05-order-inquiry-evaluation.md)는 이메일·폼 역할과 입력 검증을 다룬다. [시안 명세](../13-frontend-specification.md)는 공통 버튼·카드의 참고 구조다.

## ISSUE

같은 이름의 버튼이 상세·주문·외부 스토어로 연결되면 역할 구분 부담이 생길 수 있다. 긴 누르기·이미지 안 글씨에 의존하는 정도는 이미지 실물과 사용자 과업으로 검증해야 한다.

공통 수치는 [디자인 시스템](02-design-system.md)을 따른다. 화면의 복귀 라벨은 「돌아가기」에 목적지 이름을 덧붙이는 후보다.

### 링크·버튼·상태

이동은 링크, 열기·닫기·복사는 버튼으로 표현한다. #에 의미 없는 기능을 숨기지 않는다. 링크의 접근 가능한 이름과 실제 목적지를 맞추고, 빈 링크·중첩 링크를 새로 만들지 않는다. 로딩·빈 자료·이미지 실패·복사 실패는 사용자가 다음 행동을 알 수 있는 제안 상태로 정의한다.

이미지 모달은 비모달 모바일 메뉴와 구별한다. 터치 제스처만으로 확대/이동을 요구하지 않으며 키보드·보이는 버튼도 제공한다. 장식은 읽어주기 제외, 제품 사진은 판독 후 설명, 긴 문서 이미지는 인접 텍스트 전사 후보를 제공한다.

### 공통 안내 통합의 범위

기술·지식재산권·연락처 설명은 표현·관리 구성요소만 통합 후보다. 기존 문구와 각 페이지의 의미는 보존하며 전역 변경은 승인 후다. '통합'은 URL 병합·데이터 삭제를 의미하지 않는다.

## APPROVAL REQUIRED

C01~C10의 입력 데이터·접근성 동작·채널 라벨, 확대 모달 여부·원본 보기 대안, 오류/성공 문구. 제품 사양·가격·사례 캡션은 확보 후 승인한다.

## UNVERIFIED

원본 이미지·키보드·대체 텍스트·실제 폼 API와 오류 처리, 스토어별 제품 대응은 미확인이다. PHASE D에서는 서버 요청·실제 제출·메일 발송 없이 상태 예시만 보여준다.
