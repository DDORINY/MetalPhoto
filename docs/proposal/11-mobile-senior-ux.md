# 고연령층 모바일 과업 설계 제안

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

상태 구분: **AS-IS**는 PHASE A에서 수집한 소스의 사실, **ISSUE**는 PHASE B의 문제 또는 검증 가설, **TO-BE**는 신규 제안, **APPROVAL REQUIRED**는 내부 컨펌 필요, **UNVERIFIED**는 추가 검증 필요다. 제안 수치·문구·화면 순서는 승인된 확정값이 아니다. 화면 렌더링·이미지 실물·모바일 동작을 검증한 것으로 취급하지 않는다.

## AS-IS

[audit 19](../audit/19-page.md)는 메일·사진·규격 기재를, [audit 20](../audit/20-page.md)는 입력·jpg 첨부를, [audit 13](../audit/13-page.md)은 긴 누르기 확대 안내를 기록했다. 화면 사용성·글꼴·대비·실기기 동작은 미확인이다.

## ISSUE

[평가 M01~M07](../evaluation/06-mobile-senior-ux-evaluation.md)의 읽기·기억·정밀 조작·앱 전환 위험 가설을 검증 과업으로 연결한다. 연령을 근거로 모두가 같은 어려움을 겪는다고 단정하지 않는다.

## TO-BE — UX01 사용자 과업

| 과업 | 제안 흐름 | 부담을 줄이는 규칙 | 후속 확인 |
|---|---|---|---|
| 제품군 찾기 | 홈 2개 제품군 또는 메뉴 → 전체 목록 | 한국어 이름·원문 용도 설명, 1열 카드, 메뉴에서 모든 상세 접근 | 사용자 스스로 분류 이유를 설명하는지 |
| 사진 크게 보기 | 제품/사례 → 큰 사진 보기 → 닫기 | 숨은 길게 누르기 대신 버튼, 이전/다음, 원위치 복귀 | iOS/Android·키보드 확대/복귀 |
| 규격·차이 이해 | 모델명 → 확인된 정보·비교 | 이미지 글씨만 의존하지 않고 판독된 값 전사, 미확인 값 생성 금지 | 모델/단위/설치조건 선택 과업 |
| 주문 방법 확인 | 상세 → P19 → 준비/사진/양식 | 외부 메일 절차 명시, 복사와 접수 구분, 정책 읽기 가능 | 메일 초안 준비·첨부 선택, 실제 발송 없이 |
| 문의하기 | P20 → 입력/첨부 → 상태 예시 | 1열·18px·문의 여러 줄 후보·필수/오류 설명 | 검수 환경의 성공/실패·첨부 테스트 |
| 연락처 확인 | 헤더 진입/푸터 → 전화·이메일·주소 | 텍스트와 실행·복사 후보, 공식 값 확인 후 | 앱 미설치·복사 실패 대안 |
| 이전 화면 복귀 | 경로 표시·상위 목록·닫기·브라우저 뒤로 | 문맥 유지·가능하면 선택/스크롤 복원, 뒤로가기 가로채기 금지 | 외부 스토어·확대·메뉴 왕복 |

기본 18px·56px 버튼·간격·색상은 [공통 DS 후보](02-design-system.md)를 따른다. 큰 여백만 늘려 긴 스크롤을 만들지 않고 페이지 목차·요약·제품별 바로가기를 제공한다. 필수 정책·사양·다음 행동을 접힌 영역 안에만 숨기지 않는다.

### UX02 고정 요소·초점

모바일 하단 주문 방법/문의하기는 메뉴·확대 모달이 열리거나 문의 폼 키보드 입력 중일 때 감추는 후보다. 확대와 화면 높이 부족 시 본문 흐름으로 바꾸고 실제 하단바 높이만큼 공간을 확보한다. 포커스는 헤더·하단바에 가려지지 않아야 한다. 메뉴는 비모달, 사진 확대는 모달 계약을 구분한다.

## APPROVAL REQUIRED

과업별 우선순위·용어·하단바 예외·모바일 메뉴·큰 보기 방식, 검증 참여자와 성공 기준. 초기 3~5명 관찰은 후보이며 전체 사용자 대표성이나 통계적 검증을 보장하지 않는다.

## UNVERIFIED

320/360/390/430/768/1024/1440px, 200/400% 확대·스크린리더·키보드·화면 회전·실제 이미지 로딩은 후속 검증이다. [검증 대기 문서](../evaluation/07-remaining-visual-verification.md)의 기록 형식을 사용하며 현재 결과를 지어내지 않는다.
