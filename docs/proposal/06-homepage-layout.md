# 홈페이지 구성 제안

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

상태 구분: **AS-IS**는 PHASE A에서 수집한 소스의 사실, **ISSUE**는 PHASE B의 문제 또는 검증 가설, **TO-BE**는 신규 제안, **APPROVAL REQUIRED**는 내부 컨펌 필요, **UNVERIFIED**는 추가 검증 필요다. 제안 수치·문구·화면 순서는 승인된 확정값이 아니다. 화면 렌더링·이미지 실물·모바일 동작을 검증한 것으로 취급하지 않는다.

공통 수치는 [디자인 시스템](02-design-system.md), 요소 계약은 [공통 컴포넌트](05-shared-components.md), 경로는 [사이트맵](01-information-architecture.md)을 따른다. 아래 추가 항목은 실제 기존 콘텐츠가 아니라 확보 조건이 붙은 제안이다.

<a id="p01"></a>

## P01 — 홈

- 기존 URL 유지: http://gomemo.net/
- 근거: [PHASE A 01](../audit/01-page.md)의 「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」, [PHASE B A01](../evaluation/02-homepage-evaluation.md#a01).

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 두 제품군을 소개하고 탐색을 시작하게 하는 목적(콘텐츠에서 해석).

확인 사실: 기록·의병사진 문구 다음에 추모 영정과 기록물/기념물 이미지 링크가 등장한다. 본문 이미지 3개는 alt/title이 비어 있다.

### ISSUE — 기존 평가와 한계

브랜드 문구와 제품 선택 사이의 관계가 설명 없이 전달될 가능성. 이미지 링크의 목적이 보조기술에서 불명확할 위험. 예상 영향: 제품군을 고르기 전에 의미를 해석해야 하거나 링크를 놓칠 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 핵심 소개와 두 제품군 선택 → 6종 추모용 바로가기 → 기록물 3분야 → 기술·회사 근거 링크 → 주문 방법/문의 선택 |
| 2. 유지할 콘텐츠 | 기록·의병사진 문구와 두 제품군 원문·기존 이미지 참조는 원본 목록으로 보존 |
| 3. 재배치·강조 | 제품군 진입을 문구보다 쉽게 찾도록 상단 배치; 수명·제품 수 주장은 근거 확인 후 강조 여부 결정 |
| 4. 추가 콘텐츠·확보 조건 | 대표 이미지·최종 소개 문구·제품군 설명: 원본 판독 및 회사 승인 후 확보 |
| 5. 이미지·갤러리 | 대표 1장과 제품군 2장 후보를 기존 이미지에서 검토; 임의 대체·모델 합성 금지 |
| 6. 공통 컴포넌트 | C01·C02·C03·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 1열, 두 제품군 진입을 장식보다 먼저; 모든 상세 링크는 메뉴로도 접근 |
| 8. 다음 행동 | 제품군 전체 보기 또는 주문 방법/제작 문의 |
| 9. 탐색 진입 | 홈 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

홈 문구·대표 이미지·제품군 순서·주요 CTA. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

PC/모바일 첫 화면, 이미지 링크 접근 가능한 이름, 제품군 찾기 과업. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.
