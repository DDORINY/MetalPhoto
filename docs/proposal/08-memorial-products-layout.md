# 추모용 제품 구성 제안

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

상태 구분: **AS-IS**는 PHASE A에서 수집한 소스의 사실, **ISSUE**는 PHASE B의 문제 또는 검증 가설, **TO-BE**는 신규 제안, **APPROVAL REQUIRED**는 내부 컨펌 필요, **UNVERIFIED**는 추가 검증 필요다. 제안 수치·문구·화면 순서는 승인된 확정값이 아니다. 화면 렌더링·이미지 실물·모바일 동작을 검증한 것으로 취급하지 않는다.

공통 수치는 [디자인 시스템](02-design-system.md), 요소 계약은 [공통 컴포넌트](05-shared-components.md), 경로는 [사이트맵](01-information-architecture.md)을 따른다. 아래 추가 항목은 실제 기존 콘텐츠가 아니라 확보 조건이 붙은 제안이다.

## P05 — 추모용 메탈포토 전체

- 기존 URL 유지: http://gomemo.net/modern/
- 근거: [PHASE A 05](../audit/05-page.md)의 「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」, [PHASE B A05](../evaluation/04-product-information-evaluation.md#a05).

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 6개 추모 제품군을 비교하고 상세 또는 주문으로 연결하는 목적.

확인 사실: 모던→위패/스탠드→스페셜→VIP폴→앵글→자연장 순으로 이름·짧은 설명·상세/주문 링크가 반복된다. href=# 링크도 존재한다.

### ISSUE — 기존 평가와 한계

비교 설명의 기준이 형태·설치 위치·용도로 섞여 선택 기준이 균일하지 않을 가능성. # 링크는 JS 기능 여부 미확인. 예상 영향: 첫 구매자가 제품군 차이를 비교하거나 상세 확인과 주문을 구분하기 어려울 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 제품군 안내 → 기존 6종 선택 카드 → 검증된 차이 비교 → 주문 준비 안내 → 문의 |
| 2. 유지할 콘텐츠 | 6개 제품군 이름·설명·이미지·상세/주문 목적지를 보존 |
| 3. 재배치·강조 | 카드의 비교 축을 형태·용도·설치조건으로 정리하되 없는 값은 생성하지 않음 |
| 4. 추가 콘텐츠·확보 조건 | 비교 항목·설치조건·모델 수 최신성: 원본 판독과 담당자 확인 필요 |
| 5. 이미지·갤러리 | 제품군당 대표 이미지 후보, 자세한 사진은 각 기존 상세에서 제공 |
| 6. 공통 컴포넌트 | C01·C03·C06·C07·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 기본 1열, 6종 목차·카드 목록으로 직접 이동; 상세와 주문 버튼 구분 |
| 8. 다음 행동 | 6개 기존 상세 또는 주문 방법 |
| 9. 탐색 진입 | 추모용 > 전체 제품 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

카드 순서·비교 항목·대표 사진. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

제품군 비교 과업, # 링크 동작, 상세/주문 버튼 실제 표시. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.

## P06 — 모던

- 기존 URL 유지: http://www.gomemo.net/room/modern2/
- 근거: [PHASE A 06](../audit/06-page.md)의 「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」, [PHASE B A06](../evaluation/04-product-information-evaluation.md#a06).

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 평면형 추모 제품을 소개하고 주문으로 연결하는 목적.

확인 사실: (추모) 모던 8종·평면형 설명·주문하기 뒤에 Description, 이미지 참조, 네이버스토어 링크와 VIP폴 경로가 등장한다.

### ISSUE — 기존 평가와 한계

이메일 주문 경로와 스토어 구매 경로의 구분이 충분한지 미확인. 8종의 차이가 이미지 안에만 있을 가능성. 예상 영향: 구매 장소·선택 규격·제품명 전달 방법을 혼동할 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 제품명·평면형 설명 → 대표 이미지/전체 사진 → 8종 식별 목록 → 검증된 규격·선택 차이 → 주문 채널 안내 → 관련 제품 |
| 2. 유지할 콘텐츠 | 평면형 설명·8종 표현·16개 이미지 참조·주문 및 스토어 목적지 보존 |
| 3. 재배치·강조 | 모델 선택 정보를 주문 방법 이전에 연결; 관련 VIP폴 링크는 의미 확인 후 별도 구역 |
| 4. 추가 콘텐츠·확보 조건 | 8종과 이미지 대응·규격·색상·가격: 상품 원본과 담당자 승인 필요 |
| 5. 이미지·갤러리 | 제품 전체가 보이는 contain, 큰 사진 보기와 썸네일; 수량별 모델 배정은 판독 후 |
| 6. 공통 컴포넌트 | C01·C05·C06·C07·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 대표 사진→설명→모델→주문 순 1열; 스와이프 외 이전/다음 버튼 |
| 8. 다음 행동 | 이메일 주문 방법 또는 외부 스토어(채널 역할 승인 후) |
| 9. 탐색 진입 | 추모용 > 모던 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

8종 구성·채널 구분·추천 링크 의미. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

모델별 이미지 판독, 외부 이동 표시·복귀, 주문 채널 선택 과업. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.

## P08 — VIP폴

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 꽃꽂이형 추모 제품을 설명하는 목적.

확인 사실: VIP폴 6종과 양측 꽃꽂이 설명, 주문·스토어 링크가 있으며 개별 본문에 자기 경로 /room/vip1/ 링크도 기록됐다.

자기 경로 링크가 실제로 같은 화면을 반복시키는지 또는 이미지와 연관된 기능인지 미확인. 용어만으로 형태를 예측하기 어려울 가능성. 예상 영향: 제품 탐색이 반복되거나 제품 기능을 오해할 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

| 6. 공통 컴포넌트 | C01·C05·C06·C07·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 쉬운 설명을 이름 옆 배치, 확대 후 같은 모델 위치로 복귀 |
| 8. 다음 행동 | 주문 방법 또는 외부 스토어 |
| 9. 탐색 진입 | 추모용 > VIP폴 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
