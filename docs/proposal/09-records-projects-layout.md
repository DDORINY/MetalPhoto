# 기록물·프로젝트 구성 제안

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

상태 구분: **AS-IS**는 PHASE A에서 수집한 소스의 사실, **ISSUE**는 PHASE B의 문제 또는 검증 가설, **TO-BE**는 신규 제안, **APPROVAL REQUIRED**는 내부 컨펌 필요, **UNVERIFIED**는 추가 검증 필요다. 제안 수치·문구·화면 순서는 승인된 확정값이 아니다. 화면 렌더링·이미지 실물·모바일 동작을 검증한 것으로 취급하지 않는다.

공통 수치는 [디자인 시스템](02-design-system.md), 요소 계약은 [공통 컴포넌트](05-shared-components.md), 경로는 [사이트맵](01-information-architecture.md)을 따른다. 아래 추가 항목은 실제 기존 콘텐츠가 아니라 확보 조건이 붙은 제안이다.

## P12 — 기록물 / 기념물 전체

- 기존 URL 유지: http://gomemo.net/metalphoto/
- 근거: [PHASE A 12](../audit/12-page.md)의 「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」, [PHASE B A12](../evaluation/04-product-information-evaluation.md#a12).

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 3개 적용 분야로 상세·문의 탐색을 연결하는 목적.

확인 사실: 상패 등→명예의전당/정부조달/인테리어 등→전시/기념관/박물관의 세 묶음과 상세·문의·# 링크가 있다.

### ISSUE — 기존 평가와 한계

하나의 긴 라벨에 목적·납품 방식·설치 장소가 섞여 대상 분야를 고르기 어려울 가능성. 예상 영향: 관련 사례를 찾는 데 여러 페이지를 왕복할 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 분야 소개 → 기존 3분야 카드 → 분야별 사례 진입 → 문의 준비 항목 후보 → 제작 문의 |
| 2. 유지할 콘텐츠 | 기존 3개 분야·이미지 3개 참조·상세/문의 링크 보존 |
| 3. 재배치·강조 | 긴 복합 이름을 짧은 표제와 전체 범위 설명으로 나누는 후보 |
| 4. 추가 콘텐츠·확보 조건 | 분야별 요약·대표 사례: 실물 판독과 담당자 승인 후 확보 |
| 5. 이미지·갤러리 | 분야당 대표 사진 후보·실제 제작 범위를 확인한 캡션만 표시 |
| 6. 공통 컴포넌트 | C01·C04·C06·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 1열 분야 카드, 전체 이름은 생략 없이 읽을 수 있게 배치 |
| 8. 다음 행동 | 기존 3개 상세 또는 문의 |
| 9. 탐색 진입 | 기록물·기념물 > 전체 분야 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

분야 명칭·포함 범위·카드 순서. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

분야 선택 과업, 이미지 대응, # 및 문의 이동 확인. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.

## P13 — 상패·감사패 등

- 기존 URL 유지: http://www.gomemo.net/room/certification/
- 근거: [PHASE A 13](../audit/13-page.md)의 「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」, [PHASE B A13](../evaluation/04-product-information-evaluation.md#a13).

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 기념 제작 사례와 문의 준비 항목을 안내하는 목적.

확인 사실: 본문 제목은 증명서 및 기념품, 분류 문구는 상패/감사패/기념패/인증서이며 모바일 장기 누르기 확대 안내·문의 항목·연락처가 있다.

### ISSUE — 기존 평가와 한계

메뉴명과 제목 범위가 달라 사용자가 맞는 페이지인지 망설일 가능성. 긴 누르기 확대는 환경 의존적이다. 예상 영향: 사례와 필요한 제작 조건을 연결하거나 상세를 읽는 데 부담이 생길 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 제목·포함 범위 → 사례 목차 → 사례 이미지/확대 → 검증된 제작 정보 → 문의 준비 → 기술·증빙 |
| 2. 유지할 콘텐츠 | 원문 제목·분야명·11개 참조·지식재산권/문의 준비 문구·연락처 보존 |
| 3. 재배치·강조 | 현재 제목과 메뉴명 범위 대응을 설명; 공통 기술문구는 사례 뒤 별도 묶음 |
| 4. 추가 콘텐츠·확보 조건 | 사례명·규격·소재·수량·제작 범위: 이미지 전사와 공개 승인 필요 |
| 5. 이미지·갤러리 | 사진 큰 보기 버튼 제공, 문서형 긴 이미지는 전체와 부분 확대를 구분하는 후보 |
| 6. 공통 컴포넌트 | C01·C04·C05·C06·C07·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 세로 사례 목록과 명시적 확대/닫기, 문의 준비항목은 한 줄씩 |
| 8. 다음 행동 | 제작 문의·기록물 전체 |
| 9. 탐색 진입 | 기록물·기념물 > 상패·감사패 등 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

페이지 이름·사례 분류·확대 방식·문의 준비 항목. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

사례 이미지 내 정보, 확대 동작·복귀, 메뉴명/제목 이해 과업. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 테마파크 적용 사례와 제작 문의를 제공하는 목적.

확인 사실: 사례 이미지 참조 뒤 Description, 2016~2019 수상 문구·수상 이미지·기술 경고·문의 안내가 이어진다. cafe24 별도 호스트 이미지 참조도 있다.

### ISSUE — 기존 평가와 한계

페이지 목적보다 공통 수상·기술 문구가 이해를 지배할 가능성. 과거 수상 연도는 사실 오류로 판정하지 않는다. 예상 영향: 구체적인 적용 방식·제작 범위를 파악하기 어려울 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 제목·검증된 적용 소개 후보 → 사례 이미지 → 제작범위 후보 → 제작 문의 → 기존 수상/기술 안내 |
| 2. 유지할 콘텐츠 | 기존 사진 참조 7개·2016~2019 수상 문구·기술/문의 안내 보존 |
| 3. 재배치·강조 | 수상·기술 안내를 사례와 분리해 하단 연결 후보; 과거 기록은 삭제하지 않음 |
| 4. 추가 콘텐츠·확보 조건 | 사례명·장소·범위·사진 사용권: 실물 판독 및 담당자 승인 필요 |
| 5. 이미지·갤러리 | 사례·수상·외부 호스트 이미지를 판독 후 구분, 원본 URL 추적 유지 |
| 6. 공통 컴포넌트 | C01·C04·C05·C06·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 사례 중심 1열, 과거 수상은 날짜를 유지하며 별도 묶음 |
| 8. 다음 행동 | 제작 문의·신제품/R&D |
| 9. 탐색 진입 | 신제품·신사업 > 테마파크 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

사례 설명·수상 배치·외부 이미지 보존. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

이미지 실물·사례 정보, 문의 찾기 과업, 외부 이미지 로딩. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.
