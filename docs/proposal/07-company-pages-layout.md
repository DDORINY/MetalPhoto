# 회사·기술·증빙·신제품·방문 구성 제안

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

상태 구분: **AS-IS**는 PHASE A에서 수집한 소스의 사실, **ISSUE**는 PHASE B의 문제 또는 검증 가설, **TO-BE**는 신규 제안, **APPROVAL REQUIRED**는 내부 컨펌 필요, **UNVERIFIED**는 추가 검증 필요다. 제안 수치·문구·화면 순서는 승인된 확정값이 아니다. 화면 렌더링·이미지 실물·모바일 동작을 검증한 것으로 취급하지 않는다.

공통 수치는 [디자인 시스템](02-design-system.md), 요소 계약은 [공통 컴포넌트](05-shared-components.md), 경로는 [사이트맵](01-information-architecture.md)을 따른다. 아래 추가 항목은 실제 기존 콘텐츠가 아니라 확보 조건이 붙은 제안이다.

## P02 — 회사소개 / Portfolio

- 기존 URL 유지: http://gomemo.net/about/
- 근거: [PHASE A 02](../audit/02-page.md)의 「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」, [PHASE B A02](../evaluation/03-about-evaluation.md#a02).

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 회사와 실적을 소개해 신뢰를 형성하는 목적(제목에서 해석).

확인 사실: 개별 본문은 회사소개 (Portfolio) 제목 다음 이미지 참조 45개로 구성되며 별도 설명 텍스트가 추출되지 않았다. 해당 이미지 alt/title은 비어 있다.

### ISSUE — 기존 평가와 한계

회사·실적 정보가 이미지에 의존할 가능성. 이미지 내부 설명은 아직 읽지 않아 내용 부족을 확정할 수 없다. 예상 영향: 텍스트 검색·읽어주기·원하는 실적 찾기가 어려울 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 회사소개 제목·검증된 요약 → 페이지 내 목차 → 포트폴리오 분류 → 사례별 이미지/설명 → 기술·증빙 → 제작 문의 |
| 2. 유지할 콘텐츠 | 기존 이미지 참조 45개를 누락 없이 목록 보존. 45건의 독립 사례라고 단정하지 않음 |
| 3. 재배치·강조 | 연속 이미지를 판독 후 의미 단위로 묶되 원문·원본을 추적 가능하게 유지 |
| 4. 추가 콘텐츠·확보 조건 | 회사 소개 요약·사례명·장소·제작 범위: 이미지 전사·담당자 승인·공개권한 필요 |
| 5. 이미지·갤러리 | 고유 이미지/중복/합성 문서 구분 후 카드 구성; 원본 전체 보기 유지 |
| 6. 공통 컴포넌트 | C01·C04·C05·C06·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 목차와 1열 사례 카드, 분류 선택은 검색 기능 없이도 접근 가능 |
| 8. 다음 행동 | 기술소개·증명서 또는 제작 문의 |
| 9. 탐색 진입 | 회사·기술 > 회사소개 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

사례 분류·대표 사례·회사 소개 원문 승인. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

45개 참조의 실물·이미지 내 글씨·중복 여부, 회사 소개/실적 찾기 과업. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.

## P03 — 기술소개

- 기존 URL 유지: http://gomemo.net/introduce/
- 근거: [PHASE A 03](../audit/03-page.md)의 「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」, [PHASE B A03](../evaluation/03-about-evaluation.md#a03).

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 제작 원리·특징·다른 기법과의 차이를 설명하는 목적.

확인 사실: 역사·보존 설명, 영문, NANO Chemical Etching, 특징 7개, Laser/CNC/나노 케미컬 에칭 비교 순으로 텍스트가 등장한다. 보존 수명과 생산량 등 수치 주장이 포함된다.

### ISSUE — 기존 평가와 한계

기술·마케팅 주장이 길게 이어져 구매 판단에 필요한 정보와 근거를 구별하기 어려울 가능성. 주장의 참·거짓은 미판정. 예상 영향: 비전문 사용자가 핵심 장점과 실제 적용 조건을 이해하는 데 시간이 들 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 기술 목적 요약 후보 → 용어 설명 → 기존 원리·특징 → 검증된 비교 → 증빙 링크 → 제품군/문의 |
| 2. 유지할 콘텐츠 | 한·영 설명·특징 7개·비교 문구는 원문별 출처를 유지 |
| 3. 재배치·강조 | 요약과 자세한 설명을 구분; 기존 영문을 삭제하거나 자동 번역하지 않음 |
| 4. 추가 콘텐츠·확보 조건 | 쉬운 용어풀이·수치 조건·비교 증빙: 기술 담당자의 검증·승인 필요 |
| 5. 이미지·갤러리 | 기존 2개 참조를 판독 후 해당 설명 옆 배치; 새로운 원리도를 사실처럼 생성하지 않음 |
| 6. 공통 컴포넌트 | C01·C05·C06·C07·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 짧은 단락·섹션 목차; 비교는 항목별 묶음, 필요 시 표 스크롤 |
| 8. 다음 행동 | 추모용/기록물 전체 또는 제작 문의 |
| 9. 탐색 진입 | 회사·기술 > 기술소개 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

기술 주장·수명·생산량의 근거와 요약 문구. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

기술 담당자 증빙, 핵심 장점 설명 과업, 제목 계층·본문 실제 렌더링. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.

## P04 — 증명서 & 수상

### AS-IS — 목적과 실제 콘텐츠

자료명·발급처·연도를 텍스트만으로 찾기 어려울 가능성. 이미지 내부의 정보 및 외부 주소 접근 성공은 미확인. 예상 영향: 원하는 증빙을 특정하거나 사이트로 되돌아오는 데 부담이 생길 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

| 2. 유지할 콘텐츠 | 6개 이미지 링크와 기존 클릭 안내 원문을 보존 |

| 5. 이미지·갤러리 | 원본 전체가 잘리지 않게 표시하고 확대·닫기·원위치 복귀 제공 후보; 외부 파일 원본도 추적 |
| 6. 공통 컴포넌트 | C01·C04·C05·C06·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 1열 문서 카드, 확대 버튼 명시·이전 위치 복귀 |
| 8. 다음 행동 | 기술소개 또는 제작 문의 |

## P16 — 신제품 / R&D

- 기존 URL 유지: http://gomemo.net/%ec%8b%a0%ec%a0%9c%ed%92%88-%ec%97%b0%ea%b5%ac%ea%b0%9c%eb%b0%9c/
- 근거: [PHASE A 16](../audit/16-page.md)의 「개별 콘텐츠 — 소스 등장 순서」「이미지 참조 및 소스상 위치」, [PHASE B A16](../evaluation/03-about-evaluation.md#a16).

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 신제품·연구개발 정보와 구매 연락 경로를 제공하는 목적.

확인 사실: 제목 다음 구매 문의 전화·이메일·카카오톡 ID, 이미지 참조 1개가 있다. 이미지 alt/title은 비어 있다.

### ISSUE — 기존 평가와 한계

신제품의 종류·현재 상태가 텍스트만으로 드러나지 않을 가능성. 예상 영향: 정보를 읽기 전부터 연락해야 하거나 연구개발과 구매 가능 제품을 혼동할 수 있다. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.

### TO-BE — 페이지별 구성 제안

| 항목 | 내부 검토안 |
|---|---|
| 1. 신규 섹션 순서 | 제목 → 확인된 제품 소개 후보 → 기존 이미지/확대 → 개발·판매 상태 후보 → 문의 경로 |
| 2. 유지할 콘텐츠 | 기존 연락처·카카오톡 ID·단일 이미지 참조 보존 |
| 3. 재배치·강조 | 연락처를 지우지 않고 제품 이해 뒤 문의를 반복 제공하는 후보 |
| 4. 추가 콘텐츠·확보 조건 | 제품명·판매/연구 상태·사양·소개문: 원본 전사·담당자 확인 필요 |
| 5. 이미지·갤러리 | 단일 긴 이미지 판독 후 의미 단위 설명 추가 후보. 원본은 전체 보기로 보존 |
| 6. 공통 컴포넌트 | C01·C05·C06·C08 — [컴포넌트 계약](05-shared-components.md) 참조 |
| 7. 모바일 레이아웃 | 짧은 설명→전체 이미지/확대→연락처, 외부 앱 전환 안내 |
| 8. 다음 행동 | 제작 문의·확인된 연락처 |
| 9. 탐색 진입 | 신제품·신사업 > 신제품·R&D 및 공통 전체 메뉴. 상세는 상위 목록 복귀 링크도 제공 후보 |
| 10. 유지·통합 판정 | 페이지와 URL 유지. 공통 안내는 표현·관리 단위만 통합 후보이며 별도 페이지 삭제/redirect 없음 |

### APPROVAL REQUIRED

제품 상태·소개문·카카오 연결 가능 여부. 원문 유지 범위·추가 설명·이미지 배정과 다음 행동의 우선순위를 컨펌해야 한다. 담당자와 승인자는 미지정이다.

### UNVERIFIED

이미지 내용·담당자 제품 상태 확인, 모바일 연락 시작 과업. 실제 규격·가격·재고·사례 내용·새 문구를 이 문서에서 생성하지 않는다. 추가 정보가 없으면 PHASE D에서는 「자료 확인 필요」로 표시하고 사실을 채워 넣지 않는다.

### AS-IS — 목적과 실제 콘텐츠

목적 해석: 방문 위치와 전화 연락을 안내하는 목적.

확인 사실: 제목·오시는길 문구·도로명 주소·문의전화가 기록돼 있다. 본문 img 참조는 0개다.

### ISSUE — 기존 평가와 한계

지도·교통 안내가 소스 추출에 나타나지 않는다. JS 지도까지 없다고 단정할 수 없다. 헤더의 지번 표기와 동일 장소인지 검증 필요. 예상 영향: 방문자가 주소 확인 후 별도 지도 앱 검색이 필요할 가능성. 이는 검증 가설이며 이미지 내부 정보와 실제 화면의 결함을 확정한 것이 아니다.
