# 공통 헤더·내비게이션 제안

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

상태 구분: **AS-IS**는 PHASE A에서 수집한 소스의 사실, **ISSUE**는 PHASE B의 문제 또는 검증 가설, **TO-BE**는 신규 제안, **APPROVAL REQUIRED**는 내부 컨펌 필요, **UNVERIFIED**는 추가 검증 필요다. 제안 수치·문구·화면 순서는 승인된 확정값이 아니다. 화면 렌더링·이미지 실물·모바일 동작을 검증한 것으로 취급하지 않는다.

## AS-IS

[audit 01 공통 헤더](../audit/01-page.md)에 회사·기술·증빙, 추모용 6종, 기록물 3분야, 신제품·테마파크·오시는길이 기록됐다. 로고 이미지 src/alt는 빈 값이며 실제 로고 표현은 미확인이다. [v1.0](../../design/metalphoto_mobile_redesign.html)의 로고는 #home 이동이다.

## ISSUE

[평가 G01~G04·G07](../evaluation/01-global-navigation-evaluation.md): 복합 메뉴·독립 주문/문의 진입·URL 혼용·로고 의미·반복 링크 위험 가설. 시안의 홈 전용 앵커를 하위 페이지에 복사하면 홈 탐색 역할을 하지 못할 수 있다.

| 기록물·기념물 | 전체(P12), 상패·감사패 등(P13), 정부조달·인테리어 등(P14), 전시·기념관·박물관(P15) |

표의 로고 목적지는 홈페이지라는 의미이며 표시 문구는 한국어 「메탈포토 홈」 후보다. P번호별 URL은 [사이트맵](01-information-architecture.md)에 기록한다. 상위 그룹은 새 URL을 만들지 않는 메뉴 분류다. 전체 보기 링크와 하위 메뉴 열기 버튼을 분리한다.

## TO-BE — NAV02 PC·태블릿·모바일 동작

- 1200px 이상은 가로 상위 메뉴+명시적인 주문 방법/문의하기 진입 후보. 공간이 부족하면 조기에 전체 메뉴로 전환한다.
- 1200px 미만은 로고·「메뉴」 버튼·문의 진입을 기본으로 하는 후보. 18px 글씨를 줄여 폭을 맞추지 않는다.
- 모바일 전체 메뉴는 비모달 펼침 패널 후보다. 열면 첫 탐색 링크로 포커스를 이동하고 aria-expanded/controls/hidden을 동기화한다.
- 하위 그룹은 버튼으로 펼치며 각 페이지 링크를 별도 제공한다. hover만으로 접근시키지 않는다.
- Escape·명시적 닫기·토글 닫기는 토글로 포커스 복귀. 비모달이므로 강제 포커스 가두기는 하지 않으며 Tab은 자연스럽게 본문으로 이동한다.
- 동일 페이지 앵커 이동은 해당 제목으로 포커스 연결; 실제 페이지 이동은 브라우저 기본 이동을 유지한다. 메뉴 닫기로 포커스가 숨김 요소에 남지 않게 한다.
- PC로 전환할 때 모바일 내부 포커스가 숨겨지면 대응 PC 링크 또는 로고로 이동한다.
- 현재 페이지는 텍스트·형태 및 aria-current로 표시. 상위 분류도 사용자가 알 수 있게 한다.
- 헤더 높이는 내용에 따라 늘 수 있다. 고정 px만으로 앵커/포커스 가림을 보정하지 않는다. skip link와 적절한 스크롤 여백을 설계한다.

## APPROVAL REQUIRED

NAV01 분류·메뉴명·순서, NAV02 전환 폭·비모달 동작·고정 헤더 여부, 공식 로고. 주문 방법은 기존 URL의 메뉴 라벨 제안이며 기능이나 경로 변경이 아니다.

## UNVERIFIED

드롭다운·키보드·스크린리더·확대 실제 사용성, 공식 로고·활성 테마·WordPress 메뉴 데이터는 미확인이다. 모든 20개 경로의 실제 연결 검수는 후속 작업이다.
