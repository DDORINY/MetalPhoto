# 공통 디자인 시스템 제안

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

상태 구분: **AS-IS**는 PHASE A에서 수집한 소스의 사실, **ISSUE**는 PHASE B의 문제 또는 검증 가설, **TO-BE**는 신규 제안, **APPROVAL REQUIRED**는 내부 컨펌 필요, **UNVERIFIED**는 추가 검증 필요다. 제안 수치·문구·화면 순서는 승인된 확정값이 아니다. 화면 렌더링·이미지 실물·모바일 동작을 검증한 것으로 취급하지 않는다.

## AS-IS

[기존 명세](../13-frontend-specification.md) 3~5절과 [HTML v1.0](../../design/metalphoto_mobile_redesign.html)은 짙은 청록, 본문 18px, 최대 폭 1190px, 버튼 56px를 사용한다. 이는 시안 구현값이며 운영 사이트 측정값이나 승인 브랜드가 아니다.

## ISSUE

[고연령 UX 평가 M01~M07](../evaluation/06-mobile-senior-ux-evaluation.md)는 읽기·제스처·앱 전환 부담을 가설로 기록했다. 기존 시안의 작은 보조 문구와 메뉴 축소는 복제할 확정 규칙이 아니다. [시각 검증 목록](../evaluation/07-remaining-visual-verification.md)에 따라 실제 표시 검증이 남아 있다.

## TO-BE — DS01 컬러 후보

| 용도 | 후보 값 | 사용 조건 |
|---|---|---|
| 브랜드/주 CTA | #145363 | 흰 글씨와 조합 후보 |
| 브랜드 강조 | #0c3c48 | 선택·강조, 색 외 이름·아이콘 병행 |
| 본문 | #18252b | 흰색/밝은 배경에 사용 |
| 보조 본문 | #526069 | 필수 정보는 작은 글씨로 낮추지 않음 |
| 기본/보조 배경 | #ffffff / #f4f6f5 | 문서·제품 배경 구분 |
| 구분선 | #dbe2e2 | 단독 입력 경계로 충분하다고 가정하지 않음 |
| 입력 경계 | #667780 | 배경별 구분성 검증 필요 |
| 오류 | #a12622 | 오류 문장·아이콘 병행 |
| 성공 | #21643f | 접수 검증 전 성공 문구 노출 금지 |
| 안내/주의 | #145363 / #795000 | 밝은 배경과 검증하여 사용 |
| 포커스 | #0c3c48 + 흰색 보조 경계 | 밝은 배경은 진한 외곽, 어두운 배경은 흰 경계가 구별되게 설계 |

읽기 대비 목표는 본문 4.5:1 이상, 고연령 과업의 주요 텍스트는 가능하면 7:1, 조작 경계·상태 식별은 3:1 이상으로 검증하는 내부 목표안이다. 특정 접근성 등급 전체 충족 선언이 아니다. 원래 시안의 금색 포커스를 승인값으로 유지하지 않고 배경별 대안을 시험한다. 모든 상태 조합을 실제 측정해야 한다.

## TO-BE — DS02 타이포·그리드·여백

| 항목 | 후보 규칙 |
|---|---|
| 본문·입력·버튼·메뉴 | 기본 18px(1.125rem), 행간 1.7; 사용자 글꼴 설정/확대 허용 |
| 필수 안내·오류·모델 사양 | 기본 본문 크기 유지 |
| 부가 캡션 | 16px 후보, 필수 정보·CTA에 사용 금지 |
| 제목 | 모바일 H1 32~40px, H2 26~32px, H3 22~26px; PC H1 40~56px 후보 |
| 폰트 | 시스템 한글 글꼴 우선 후보. Pretendard/Noto는 라이선스·파일·용량 확보 후 결정 |
| 폭 | 콘텐츠 최대 1190px, 긴 본문 읽기 폭 약 720px 후보 |
| 좌우 여백 | 모바일 18px, 태블릿 24px, PC 32px 후보; 확대 시 줄바꿈 허용 |
| 격자 | 기본 1열, 768px 이상 2열, 1200px 이상 카드 최대 3열 후보 |
| 여백 척도 | 4/8/12/16/24/32/48/64/80px 후보 |
| 섹션/문단 | 모바일 48~64px, PC 64~80px; 문단 16~24px, 관련 정보는 가까이 |
| 내비게이션 전환 | 1200px 미만 전체 메뉴형 후보. 글자를 14px로 줄여 맞추지 않음 |
| 표 | 내용은 보존, 좁은 화면은 항목별 묶음 또는 명시적 표 스크롤 |

제목 수준은 정보 계층에 맞추며 외관 크기를 위해 h태그를 건너뛰지 않는다. 긴 숫자·URL은 필요한 위치에서 줄바꿈하고 가로 넘침을 검사한다. 후보 폭은 장치 종류를 단정하는 기준이 아니며 콘텐츠·확대에 따라 변경 가능하다.

## TO-BE — DS03 조작·미디어

버튼은 최소 높이 56px, 메뉴 항목/아이콘 조작은 최소 48×48px, 간격 8~12px 후보다. 라운드 12px(버튼)·18px(카드)는 시안 참고값이다. 두 개의 행동을 하나의 카드 링크 안에 중첩하지 않는다.

제품 사진은 4:3 또는 1:1 프레임 후보에 contain으로 전체 보존, 사례 사진은 원비율 우선이다. 증명서·긴 안내 이미지를 억지로 자르지 않는다. 의미 없는 장식만 빈 alt, 상품·문서는 실제 판독한 정보로 대체 설명을 작성한다. 확대에는 보이는 버튼·닫기·이전/다음·원위치 포커스가 필요하다.

모바일 하단 주문 방법/문의하기 2열은 콘텐츠·키보드·확대에 방해되지 않을 때만 사용한다. 실제 높이+safe area를 본문에 확보하고 폼 입력 중에는 숨김 후보다. 200/400% 확대에서 공간이 부족하면 고정 대신 본문 흐름으로 전환한다. 모션 감소 설정을 존중하며 자동 슬라이드는 기본 제안에서 제외한다.

## APPROVAL REQUIRED

컬러·폰트·타이포·그리드·버튼 크기·하단바·브랜드 로고와 이미지 규칙(DS01~03). 다른 문서는 이 파일을 공통 수치의 단일 기준안으로 참조한다.

## UNVERIFIED

색상 조합 전체의 측정, 폰트 렌더링, 실기기 확대·터치·키보드, 고정 요소 가림, 원본 이미지와 저작권은 미확인이다.
