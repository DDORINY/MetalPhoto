# 내부 컨펌 및 후속 단계 조건

작성일: 2026-10-26 (KST) · 상태: **내부 검토용 Draft / 미승인**

**AS-IS**는 수집 소스의 사실, **ISSUE**는 기존 평가의 문제/가설, **TO-BE**는 제안, **APPROVAL REQUIRED**는 컨펌 필요, **UNVERIFIED**는 추가 검증 필요를 뜻한다. 승인 전 구현·최종안으로 취급하지 않는다.

## AS-IS

[PHASE A](../audit/00-audit-index.md)는 HTML 소스, [PHASE B](../evaluation/00-evaluation-index.md)는 위험 가설을 기록했다. [v1.0 명세](../13-frontend-specification.md)는 시안 Draft다. 컨펌 완료 기록은 현재 없다.

## ISSUE

화면·이미지 미검증을 설계 승인으로 오해하거나 이메일 주문을 새 서버 기능으로 바꾸면 기존 콘텐츠·업무 흐름이 손상될 수 있다. [OI01~05](../evaluation/05-order-inquiry-evaluation.md), [시각 검증 대기](../evaluation/07-remaining-visual-verification.md)가 근거다.

### 페이지별 승인표

P01~P20 각각 다음을 기록한다: 원문 유지 확인 / 섹션 순서 / 대표 이미지 / 추가 자료 / CTA·복귀 / 모바일 예외 / 보류사항 / 승인자 / 승인일. 일부 승인으로 전체 페이지를 승인했다고 간주하지 않는다.

## APPROVAL REQUIRED — 단계별 구분

1. PHASE C 문서 검토: 메뉴·공통 후보와 페이지 순서를 검토한다.
2. PHASE D 착수: 별도 사용자 지시 후 정적 시안을 만든다. 미확보 콘텐츠는 자료 확인 필요로 표시하고 운영 발송은 하지 않는다.
3. 실제 WordPress 개발: 활성 구성·DB/플러그인/이미지·의존성·격리 환경을 확인한 뒤 별도 범위 결정.
4. 운영 배포: 백업·복원·회귀·신규 문의 보존과 사용자 명시적 승인 후 별도 수행. 디자인 컨펌은 배포 승인이 아니다.

담당자·승인자는 아직 미지정이며 시간 경과를 승인으로 간주하지 않는다. 이번 문서 생성만으로 사용자에게 구현·서버 접속·Push 승인을 요청하거나 실행하지 않는다.

## UNVERIFIED

실사이트 시각·이미지·모바일·문의 동작·현재 운영 정책·원본 사용권·활성 테마는 미확인이다. 보류 항목이 있으면 해당 화면에 조건을 남기고 확정 콘텐츠로 채우지 않는다.
