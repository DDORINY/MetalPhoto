## ISSUE

[평가 G05·G06](../evaluation/01-global-navigation-evaluation.md): 재탐색·연락 경로와 주소 대응 검토가 필요하다. 기존 문자열이 동일한 푸터라는 사실은 내용의 최신성을 증명하지 않는다.

## TO-BE — FT01 내용 순서

공식 로고/회사명 → 확인된 전화·이메일·주소 → 주문 방법/문의하기 → 제품군/회사·기술/신사업의 전체 메뉴 링크 → 승인된 회사·개인정보 관련 정보 → 저작권 순서 후보다. 모바일은 1열, 긴 주소는 줄바꿈한다. 모든 링크는 기존 20개 URL을 사용하며 홈·각 하위 페이지에도 돌아갈 수 있다.

전화·이메일 실행과 복사 기능 후보는 [연락 컴포넌트 C08](05-shared-components.md)를 따른다. 사용자에게 복사 성공을 알리고 앱이 없을 때 읽을 수 있는 텍스트를 남긴다. 하단바 여백은 고정 125px 복제보다 실제 높이+safe area 기준 후보다.

## TO-BE — FT02 미확보 회사정보

사업자등록번호·통신판매 정보·개인정보처리방침 URL은 확인되지 않았다. 번호·정책 본문·가짜 링크를 생성하지 않는다. 담당자에게 기존 정책과 승인된 표시 정보를 요청하며 확보 전 PHASE D에 「운영 정보 확인 필요 — 시안」으로 구분한다. 검증되지 않은 회사정보를 실제 운영 정보처럼 추가하지 않는다.

## APPROVAL REQUIRED

최신 연락처·주소·대표/책임자, 상담시간 표기 범위, 회사명 표기, 법적 정보·정책 링크, 푸터 메뉴와 저작권 표기. 승인된 원문과 근거를 남긴다.

## UNVERIFIED

주소의 동일 장소 여부, 공식 연락 채널, 회사정보의 최신성, 법적 표시 적정성, 하단바와의 실제 겹침은 미검증이다.
